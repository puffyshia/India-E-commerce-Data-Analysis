# <div align="center">India E-commerce Operations Analysis  </div>

## 1. 專案背景  
電商企業累積大量顧客、商品與交易資料，如何從資料中發現營運問題、萃取商業洞察並支持決策，是資料分析的重要職能。本專案以`印度電商交易資料集`為基礎，涵蓋共四萬名會員、商品資訊與逾 20 萬筆訂單明細，模擬實際電商營運分析情境。依分析需求使用 SQL 進行資料查詢與彙總、 Python （ Pandas ）進行資料處理與分析，並以 Power BI 呈現視覺化。整體依「銷售、商品、顧客、促銷、留存／回購」五大面向展開，從營收與訂單流失、商品組合與定價，到顧客分級、優惠券效益及回購行為，逐步拆解電商營運問題，從資料探索延伸至顧客價值與留存分析，建立完整的電商營運分析架構。
## 2. 分析目的  
本專案旨在透過資料分析辨識電商營運現況、異常與潛在風險，進一步釐清影響業績與顧客行為的關鍵因素。透過資料驗證各項指標與行為之間的關聯，辨識值得關注的營運現象，並將分析結果轉化為具商業意義的洞察，作為後續營運優化與資源配置的數據依據。
## 3. 資料集介紹  
本專案採用印度電商交易資料集，由三張關聯表組成，涵蓋顧客、商品與訂單三大構面。  

- customers （顧客資料）：共四萬筆會員資料，包含 Customer_ID 、性別、年齡層、註冊日期、會員等級、累計訂單數與累計消費金額等欄位，可用於顧客輪廓與價值分層分析。  

- products （商品資料）：涵蓋商品編號、品類、品牌、折扣幅度、庫存量、平均評分等欄位，可用於商品組合、定價與庫存狀況分析。  

- sales （訂單交易明細）：逾 20 萬筆交易明細，包含訂單編號、顧客編號、商品編號、下單日期、訂單金額、運費、優惠券代碼與折扣、付款方式、訂單狀態、評分等欄位，為核心交易行為資料。  

三張表可透過  Customer_ID、Product_ID  相互關聯，串接顧客、商品與交易資訊，建立電商營運分析的資料基礎。

## 6. 分析結果與商業洞察  

### 銷售分析｜營收成長與訂單趨勢
- 主要發現  
  月營收長期在 2.15～2.48 億間平穩震盪， 3 個月移動平均無明顯成長或衰退趨勢；營收前三大邦（ UP、Rajasthan、Haryana ）皆位於北印度，雖然排名靠前，但單一邦占比僅約 13% ，因此未形成明顯的單一地區依賴。已送達訂單占 80% ，取消／退貨合計約一成，且主要來自 UPI 與 COD 付款； Credit Card 客單價最高，物流成本占比最低。  
- 商業洞察  
  目前營收呈現穩定震盪，尚未觀察到明顯成長趨勢，後續可從新市場拓展與商品策略調整尋找成長機會。取消／退貨訂單主要來自 UPI 與 COD ，建議進一步比較各付款方式的取消／退貨率，以確認是否存在較高風險，並針對高流失情況改善訂單管理流程。  

### 商品分析｜商品組合與定價調整  
- 主要發現  
  Electronics 品類貢獻 72.62% 營收， HP、Noise 等品牌包辦營收前五名， Grocery、Beauty、Books 合計不到 2% 。 10% 以下折扣區間訂單量明顯低於其他區間， 11% 以上各區間則較為接近，整體相關係數僅 0.02 。高評價商品未必有高銷量。 1,000 天售罄天數門檻涵蓋多數商品，難以有效區分庫存去化程度。  
- 商業洞察  
  營收高度集中於 Electronics ，可評估強化 Home、Sports 等次要品類，分散品類依賴。折扣與銷量的線性關係弱，應進一步比較不同折扣區間的銷售表現與毛利影響。商品評價與銷量關係不單純，可搭配價格、品牌等因素分析。庫存則建議依品類分層比較，改善去化效率。  

### 顧客分析｜顧客分級與輪廓洞察  
- 主要發現  
  全體 Gini 係數為 0.47 ，消費分布存在一定程度集中； Platinum 會員占全體會員約 69% ，卻貢獻 93.96% 營收，營收高度集中於 Platinum 會員。RFM 分群中，核心 VIP 有 5,206 位，重點挽留客有 2,313 位。18–45 歲客群以 Electronics 為主要品類， 46 歲以上則以居家用品為主。各邦會員規模與平均訂單金額交錯分布，未呈現明顯集中趨勢。  
- 商業洞察  
  營收高度集中於 Platinum 會員，且該族群內部 Gini 係數仍為 0.32 ，顯示會員內部消費貢獻仍有差異，可透過 Gold／Silver 會員升級與培育降低單一等級依賴。2,313 位重點挽留客具高消費價值但近期未活躍，可作為召回行銷的優先客群。品類經營則可依年齡層差異調整商品曝光與推薦方向。  

### 促銷分析｜優惠券與折扣效益評估  
- 主要發現  
  有優惠券訂單平均金額（ 24,299.94 ）高於無優惠券訂單（ 23,884.46 ）， t 檢定 p 值 0.0282 達統計顯著，但差距幅度有限。三張優惠券 ROI 差異明顯： FLAT50 高達 483 倍、 DIWALI100 約 244 倍， SAVE10 雖營收最高但成本也最高， ROI 僅 9 倍。促銷訂單中新客占比 19.67% ，約八成來自既有客戶。  
- 商業洞察  
  優惠券策略應從單純追求營收規模，轉向兼顧成本與客群目的。可依優惠券成本與回報差異調整資源配置，並將既有客戶促購與新客獲取分開設計。針對新客，可規劃新客專屬優惠或搭配其他拉新管道，提高促銷資源的使用效率。  

### 留存／回購分析｜顧客留存與回購行為分析  
- 主要發現
  整體回購率達 96.02% ，多數顧客有二次以上購買行為；回購間隔中位數 70 天，平均 98.7 天呈右偏分布，部分顧客週期較長。 Cohort 留存率穩定落在 20%～24% ，未見持續下滑。評價 ≥2 分客群回購率約99%，低評價／無評分客群僅 86.59% 。另篩出 3,466 位高價值沉睡顧客。  
- 商業洞察  
  整體回購率高，但流失風險集中於特定客群，可優先鎖定「高消費、低評價、久未購買」者。 Top 50 高風險高價值名單（ R=1、F=5、M=5 ）可優先進行客製化召回；低評價／未評分客群回購率較低，亦可加強售後體驗與後續追蹤。

## 7. 總結與建議  
核心發現： 整體營收表現穩定，但商品與顧客營收存在高度集中；促銷活動的投入效益差異明顯；整體回購率雖高，仍存在值得關注的高價值沉睡客群。  
分析結論： 電商營運目前的主要議題並非單純追求營收成長，而是降低結構性依賴、提升促銷資源配置效率，以及針對高價值客群進行分層經營。後續可持續追蹤商品組合、庫存、促銷效益與顧客回購等指標，作為營運優化的數據依據。
